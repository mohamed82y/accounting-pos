# نظام المحاسبة ونقطة البيع

## التشغيل على ويندوز
1. ثبّت Node.js (الإصدار 22.13 أو أحدث) من https://nodejs.org
2. اضغط مرتين على `start.bat` (أول مرة يثبّت المكتبات تلقائياً ويفتح المتصفح).

## التشغيل بالأمر
    npm install
    npm start        # http://localhost:3000

الدخول الافتراضي: `admin` / `admin123` — غيّر كلمة المرور فوراً من شاشة المستخدمين.

## ملاحظات
- البيانات في ملف `data.db` (انسخه للنسخ الاحتياطي).
- للوصول من أجهزة أخرى على نفس الشبكة افتح `http://<عنوان-الجهاز>:3000`.
- للنشر على الإنترنت: ضعه خلف HTTPS (Nginx/Caddy) وغيّر كلمة مرور المدير.
- متغيرات: `PORT` و `DB_FILE`.

## برنامج ويندوز (Electron)
- تجربة مباشرة: `npm install` ثم `npm run desktop`.
- بناء ملف التثبيت `Setup.exe` على ويندوز: `npm install` ثم `npm run dist:win` (النتيجة في مجلد `dist`).
- أو ارفع المشروع إلى GitHub وشغّل workflow باسم **Build Windows installer** وحمّل الملف الجاهز.
- في نسخة سطح المكتب تُحفظ البيانات في `%APPDATA%\accounting-pos\data.db`.
